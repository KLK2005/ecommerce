# ShopCam - Site E-commerce Cameroun

Site e-commerce d'essai adapté au marché camerounais (Prix en FCFA, Paiement Mobile Money et à la livraison, adresses locales sans code postal).

## 🚀 Technologies utilisées
- **React** (avec Vite)[cite: 1]
- **Tailwind CSS** (pour le design)[cite: 1]
- **React Router** (navigation entre les pages)[cite: 1]
- **Context API & localStorage** (gestion du panier, favoris, utilisateurs et commandes)[cite: 1]

## 🛠️ Installation et lancement local

1. Cloner le projet :
   ```bash
   git clone [https://github.com/KLK2005/ecommerce.git](https://github.com/KLK2005/ecommerce.git)
   cd ecommerce
Installer les dépendances :
Bash
npm install

Lancer le serveur de développement :
Bash
npm run dev

Tester la compilation de production :
Bash
npm run build
